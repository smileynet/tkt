# Reference checkouts

Read-only upstream sources used to compare ticket workflows, release tooling, and
terminal interfaces. Clone from the repository root; checkout contents are ignored.
These are exploratory references, not pinned build dependencies.

## beads
Git-backed issue tracking comparison.
`git clone https://github.com/gastownhall/beads .references/beads`

## cargo-release
Rust release workflow reference.
`git clone https://github.com/crate-ci/cargo-release.git .references/cargo-release`

## cube
Large Rust/JavaScript repository architecture reference.
`git clone https://github.com/cube-js/cube.git .references/cube`

## git-cliff
Changelog generation reference.
`git clone https://github.com/orhun/git-cliff.git .references/git-cliff`

## gum
Terminal interaction reference.
`git clone https://github.com/charmbracelet/gum.git .references/gum`

## icdiff

`git clone https://github.com/jeffkaufman/icdiff.git .references/icdiff`

## just
Command runner interface reference.
`git clone https://github.com/casey/just.git .references/just`

## markdownlint-cli2
