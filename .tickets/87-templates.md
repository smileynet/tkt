# tkt new --template: predefined ticket body structures

## Context

Teams standardize on ticket formats (bug reports, feature requests, spikes). A template system lets `tkt new --template bug` pre-fill the body with a structured layout.

## What to build

```bash
tkt new fix-crash --title "Fix null crash" --template bug
# → Creates ticket with bug report body template
```

Templates stored in `.tickets/templates/`:
```
.tickets/templates/
├── bug.md
├── feature.md
└── spike.md
```

Template files contain only the body (below frontmatter). Frontmatter is generated by tkt as usual.

## Acceptance criteria

- [ ] `--template <name>` flag on `tkt new` and `tkt batch`
- [ ] Templates read from `.tickets/templates/{name}.md`
- [ ] Template content becomes ticket body (below frontmatter)
- [ ] Error if template name doesn't match a file
- [ ] Works without templates directory (flag simply unavailable)
- [ ] Templates are plain markdown (no variable interpolation needed for v1)
