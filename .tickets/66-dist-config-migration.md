# Migrate [workspace.metadata.dist] to dist-workspace.toml

## What to build

After v0.1.0 ships (cargo-dist init generates its own config), remove the manually-written `[workspace.metadata.dist]` section from Cargo.toml. cargo-dist v0.23+ prefers a standalone `dist-workspace.toml` file. The init wizard will create one — this ticket tracks cleaning up the old location afterward.

Current state: Cargo.toml lines 29-39 contain `[workspace.metadata.dist]` with targets, installers, and archive format. After `cargo dist init` runs (ticket #01), this section becomes redundant.

## Acceptance criteria

- [ ] `[workspace.metadata.dist]` section removed from Cargo.toml
- [ ] `dist-workspace.toml` exists with equivalent config (generated by cargo dist init)
- [ ] `cargo dist plan` still produces correct release plan after removal
- [ ] No duplicate/conflicting dist config between the two locations
