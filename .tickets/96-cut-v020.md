# Cut v0.2.0 release

## What to build

After completing the blocking tickets, cut a v0.2.0 release:

1. Update CHANGELOG.md `[Unreleased]` → `[0.2.0] - DATE`
2. Bump version in Cargo.toml to 0.2.0
3. `cargo publish`
4. Tag `v0.2.0`, push tag (triggers cargo-dist release workflow)
5. Verify GitHub Releases + install script

## Acceptance criteria

- [ ] CHANGELOG.md has a dated 0.2.0 section
- [ ] Cargo.toml version = "0.2.0"
- [ ] `cargo publish` succeeds
- [ ] v0.2.0 tag pushed, GitHub Release with 5 platform binaries
- [ ] `cargo install tkt` installs 0.2.0
